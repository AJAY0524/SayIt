# Triage 標籤

skills 以五個標準 triage 角色描述狀態。下表把角色對應到本 repo（`AJAY0524/SayIt`）實際使用的標籤字串。五個標籤皆已在 fork 建立（2026-11-06）。

| mattpocock/skills 的角色 | 本 repo 的標籤 | 意義 |
| ------------------------ | -------------- | ---- |
| `needs-triage`           | `needs-triage`    | 維護者需要評估這張票 |
| `needs-info`             | `needs-info`      | 等回報者補資訊 |
| `ready-for-agent`        | `ready-for-agent` | 規格完整，可交給無人值守的 agent |
| `ready-for-human`        | `ready-for-human` | 需要人工實作 |
| `wontfix`                | `wontfix`         | 不處理 |

skill 提到某個角色（例如「apply the AFK-ready triage label」）時，用上表對應的標籤字串。

要改名就改「本 repo 的標籤」欄，並同步在 GitHub 改標籤名稱。
